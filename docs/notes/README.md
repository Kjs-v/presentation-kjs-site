# Work notes: one file per person

Everyone who works on this repo keeps their own notes file here. This avoids merge conflicts.

## Rules

1. **Say who you are first.**
   - Before writing any note, identify yourself by your first name, in lowercase.
   - AI assistants must ask the person they are working for and use that person's name.
2. **Find your file:** `docs/notes/<your-name>.md`, for example `docs/notes/vineet.md`.
3. **New here? Create your file first.**
   - Copy `_TEMPLATE.md` to `docs/notes/<your-name>.md`.
   - Fill in the header, then start writing.
4. **Only edit your own file.** Never change someone else's notes. To respond to them, write in your own file and mention their name.
5. **Add new entries at the top**, under today's date (`YYYY-MM-DD`).
6. **Shared decisions** that affect everyone go in `docs/PLAN.md`. Discuss them with the team before editing it.
